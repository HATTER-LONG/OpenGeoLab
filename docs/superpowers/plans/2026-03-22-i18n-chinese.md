# 中文切换支持 实现计划

> **执行要求：** 按任务逐项执行，优先使用 superpowers:subagent-driven-development；如果不使用子代理流程，则使用 superpowers:executing-plans。步骤使用复选框语法记录进度。

**目标：** 为 OpenGeoLab 应用实现 en_US ↔ zh_CN 运行时语言切换，覆盖全部 ~41 条 qsTr() 字符串。

**架构：** 新增 TranslationManager C++ singleton（QML_SINGLETON + static create()），由 QML 引擎自动创建。CMake 使用 qt_add_translations() 编译 .ts → .qm 并嵌入 Qt 资源。QML 层删除手工语言属性链，改为直接读取 singleton 状态。

**技术栈：** Qt 6 (C++20, QML, qt_add_translations), CMake, Ninja

**规格文档：** docs/superpowers/specs/2026-03-22-i18n-chinese-design.md

## 任务 1：TranslationManager C++ 类

**文件：**
- 新增：`src/app/include/opengeolab/app/translation_manager.h`
- 新增：`src/app/src/translation_manager.cpp`

**TDD 说明：** TranslationManager 依赖 QQmlEngine 和 Qt 资源系统，无法在当前项目测试基础设施内轻量验证。采用手工验证（任务 4）替代单元测试。

- [ ] 步骤 1：创建头文件 `translation_manager.h`

  ```cpp
  #pragma once

  #include <QObject>
  #include <QTranslator>
  #include <QtQml/qqmlregistration.h>

  class QQmlEngine;
  class QJSEngine;

  /// @brief Runtime language switcher exposed as QML singleton.
  class TranslationManager : public QObject {
      Q_OBJECT
      QML_ELEMENT
      QML_SINGLETON
      Q_PROPERTY(QString currentLanguage READ currentLanguage
                 WRITE switchLanguage NOTIFY currentLanguageChanged)

  public:
      static TranslationManager* create(QQmlEngine* engine, QJSEngine*);

      [[nodiscard]] auto currentLanguage() const -> QString;
      Q_INVOKABLE void switchLanguage(const QString& locale);

  signals:
      void currentLanguageChanged();

  private:
      explicit TranslationManager(QQmlEngine* engine, QObject* parent = nullptr);

      QQmlEngine* m_engine = nullptr;
      QTranslator m_translator;
      QString m_currentLanguage{"en_US"};
  };
  ```

- [ ] 步骤 2：创建实现文件 `translation_manager.cpp`

  关键逻辑：
  - `create()`: `return new TranslationManager(engine, engine);`
  - `switchLanguage(locale)`:
    - 如果 locale == m_currentLanguage，直接返回
    - `QCoreApplication::removeTranslator(&m_translator)` 移除旧翻译
    - 如果 locale != "en_US"，从 `:/translations/opengeolab_<locale>.qm` 加载
    - `QCoreApplication::installTranslator(&m_translator)` 安装新翻译
    - 更新 m_currentLanguage
    - `m_engine->retranslate()` 刷新 QML 绑定
    - emit currentLanguageChanged()

- [ ] 步骤 3：确认文件编译通过（需要任务 2 的 CMake 配置才能实际编译）

  在 `openActionPage` 函数中增加 `switchLanguage` 处理（关闭菜单 + 更新状态消息）：
  ```qml
  function openActionPage(actionKey) {
      if (actionKey === "toggleTheme") {
          root.toggleTheme();
          return;
      }
      if (actionKey === "switchLanguage") {
          root.statusNote = TranslationManager.currentLanguage === "zh_CN"
              ? qsTr("Switched to Chinese.") : qsTr("Switched to English.");
          root.menuOpen = false;
          return;
      }
      root.statusNote = qsTr("Action: %1").arg(actionKey);
      root.menuOpen = false;
      console.log("[Main] openActionPage:", actionKey);
  }
  ```

  > 注意：TranslationManager.switchLanguage 在 HeaderMenuPanel 中先调用，到达 openActionPage 时语言已经切换完毕，此处只负责 UI 状态更新。

  Components.ActionButton {
      theme: panel.theme
      width: parent.width
      buttonText: TranslationManager.currentLanguage === "zh_CN"
          ? qsTr("Switch to English") : qsTr("Switch to Chinese")
      iconKind: "language"
      leftAligned: true
      buttonColor: panel.theme.tint(panel.theme.accentE, panel.theme.darkMode ? 0.18 : 0.1)
      pressedColor: panel.theme.tint(panel.theme.accentE, panel.theme.darkMode ? 0.28 : 0.16)
      hoverBorderColor: panel.theme.tint(panel.theme.accentE, panel.theme.darkMode ? 0.58 : 0.34)
      onClicked: {
          TranslationManager.switchLanguage(
              TranslationManager.currentLanguage === "zh_CN" ? "en_US" : "zh_CN")
          panel.triggerAction("switchLanguage")
      }
  }
  ```

  > 语言切换通过 TranslationManager 完成后，经 triggerAction → openActionPage 链路关闭菜单并更新 statusNote。

  ## 7. 国际化 (i18n)

  - 所有用户可见字符串必须使用 `qsTr()` 包裹，包括按钮文本、标签、状态消息和占位文本。
  - 带参数的字符串使用 `qsTr("Action: %1").arg(value)`，不要拼接字符串。
  - 语言切换通过 `TranslationManager` QML singleton 管理，不要在 QML 中维护手工语言属性。
  - 新增 QML 文件时，确认所有硬编码英文文本已用 `qsTr()` 包裹。
  - 新增翻译字符串后，需要同步更新 `src/app/resource/translations/opengeolab_zh_CN.ts` 中对应的 context。
  - `.ts` 文件中的 context name 对应 QML 文件名（不含 .qml 后缀）。
  - 不要在 QML 中使用条件表达式手工切换语言文本，依赖 Qt 翻译机制自动处理。
  ```
