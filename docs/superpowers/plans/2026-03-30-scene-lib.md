# Scene Lib 实现计划

> **执行要求：** 按任务逐项执行，优先使用 superpowers:subagent-driven-development；如果不使用子代理流程，则使用 superpowers:executing-plans。步骤使用复选框语法记录进度。

**目标：** 新增 `opengeolab_scene` 库，提供通用场景图、组合式组件接口、PickId 编解码、拓扑关系索引和 ShapeStore 自动同步桥接。

**架构：** Scene lib 是一个不依赖 Qt 和 OpenGL 的纯 C++20 库。SceneNode 采用组合式设计（Transform + Visibility + 可选 IRenderComponent / IPickComponent），GeometrySceneBridge 监听 ShapeStore 信号自动构建场景节点和渲染数据。所有类型都可以在无 GL 环境下完整测试。

**技术栈：** C++20, GLM 1.0.1, OpenCASCADE (间接依赖 via geometry), doctest, Kangaroo Signal

**规格文档：** `docs/superpowers/specs/2026-03-30-scene-render-design.md` §3

> **与规格的偏差说明：**
> - 规格 §3.1 定义了 `Transform3D` 独立类型。本计划初始版本简化为直接使用 `glm::mat4`，后续如需额外的旋转/缩放分量存储或脏标记，再提取 `Transform3D` 包装。
> - 规格将 `BoundingBox3D` 放在 `render_mesh_data.hpp` 中。本计划将其拆为独立文件 `bounding_box3d.hpp`，因为 SceneNode 也直接使用它，独立文件更清晰。
> - 规格列出 `render_mesh_data.cpp` 和 `pick_id.cpp`。本计划将其实现为 header-only（纯数据结构 + constexpr 函数），更简洁。

**文件：**

**关键接口（参照规格 §3.7）：**
```cpp
namespace OpenGeoLab::Scene {
class OPENGEOLAB_SCENE_EXPORT GeometrySceneBridge final {
public:
    GeometrySceneBridge(SceneGraph& scene,
                        Geometry::ShapeStore& store,
                        TopologyIndex& topoIndex);
    ~GeometrySceneBridge();

private:
    void onShapeAdded(uint32_t shape_id, const Geometry::ShapeEntry& entry);
    void onShapeRemoved(uint32_t shape_id);
    void onShapeUpdated(uint32_t shape_id, const Geometry::ShapeEntry& entry);

    static RenderMeshData buildRenderData(uint32_t shape_id,
                                          const Geometry::ShapeEntry& entry);
};
} // namespace OpenGeoLab::Scene
```

**buildRenderData 实现要点：**
- 遍历 `VisualData.surfaces`（每个对应一个 Face）：
  - 将 `SurfaceMesh.positions/normals/colors` → `RenderVertex[]`
  - 用 `triangleTags[i]` 为每个三角形的三个顶点生成 `PickIdEntry`
  - 记录 `DrawRange`（三角面）
- 遍历 `VisualData.edges`（每个对应一个 Edge）：
  - 将 `EdgeMesh.positions` → `RenderVertex[]`（normal 为零，color 为 edge color）
  - 用 `edgeTags[i]` 生成 `PickIdEntry`
  - 记录 `DrawRange`（线段）
- 遍历 `VisualData.points`：
  - 将 `PointSet.positions` → `RenderVertex[]`
